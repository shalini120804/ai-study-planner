# AI-Assisted Study Planner

This project demonstrates a simple AI-assisted study planner that helps students
organize and prioritize study tasks efficiently.

## Features
- Automated task prioritization
- Deadline-based urgency scoring
- Simple and extensible AI logic
- Easy to adapt for web or mobile platforms

## How It Works
Tasks are assigned a priority score based on urgency and importance.
The planner dynamically sorts tasks to generate an optimized study plan.

## Tech Stack
- Python

## Usage
Run the `study_planner.py` file to see a sample prioritized study plan.
